# DailyOne · 每日一题 1.4.0

仅展示国内力扣 leetcode.cn 的每日一题。Android 8.0+，开发者 π。同包名、同签名，可覆盖安装旧版。

## 1.4.0 更新

- 勋章统一尺寸，名称最多显示两行，增加时间 / 类型标签；默认展示 8 枚，可展开全部。
- 点击勋章查看大图、名称、类别和获得日期；支持图片加载失败占位和延迟加载。
- 底部增加“检查更新”：查询本仓库的 `update.json`，显示最新版、新版下载入口或失败原因。
- 新版下载只允许本仓库 GitHub Release 的 HTTPS APK 地址；不会携带力扣 Cookie，也不静默安装。
- 保留原生登录表单、唯一账号入口、切换账号和独立草稿。

## 安装

在 [Releases](https://github.com/lyz10-26/dailyone-android/releases) 下载 APK。首次安装需要允许当前下载来源安装应用；后续相同签名版本可覆盖安装。

## 功能

资料卡展示头像、昵称、积分、累计通过数、全站排名和全部勋章（分页）。每日一题按北京时间日期更新。

代码区支持官方可用语言的搜索和模板切换、多语言语法高亮、行号、4 空格缩进、草稿、复制、重置和专注模式。提交原始代码至官方，按判题结果显示完成状态；超时保留提交编号，支持继续核验。积分仅展示官方查询值，不伪造领取成功。

## 架构

| 文件 | 职责 |
| --- | --- |
| `MainActivity.java` | 页面导航、唯一账号入口及账号管理 |
| `AuthController.java` | 原生登录 UI、Cookie 清理顺序、登录生命周期、超时及成功回调 |
| `UpdateController.java` | 手动检查更新、网络错误与新版下载提示 |
| `UpdatePolicy.java` | 版本比较和下载来源限制 |
| `WebSupport.java` | WebView 安全设置、官方来源校验、JSON 解码及销毁 |
| `auth-page.js` | 对接同源官方密码表单；显式提交、错误读取、登录结果及必要安全验证 |
| `dashboard.js` | 个人信息、题目渲染、编辑器交互、提交和判题 |
| `editor-core.js` | 纯文本语法着色、HTML→Markdown→HTML 转换 |

原生顶部直接展示账号界面，不等待 WebView 执行查询。主界面通过限制目标来源的 WebMessagePort 同步公开账号标识与任务忙碌状态，消息不包含密码或代码。页面导航后关闭旧端口，旧页面消息不会覆盖新页面状态。

## 登录与数据

原生账号密码输入仅在当前会话使用，不保存到应用文件、localStorage 或日志，取消和成功后清空输入。只向 `https://leetcode.cn` 的官方密码表单传递输入，由官方表单处理密码登录和安全校验；不绕过官方验证。若官方要求图形验证或二步验证，会显示必要认证界面。表单未就绪、网络失败或超时提供重新连接入口。

登录依赖官方页面结构与内部接口，后续可能需要适配。没有使用私人账号完成真实登录测试。

Cookie 存放于本应用 WebView。草稿只在本地保存，卸载会丢失。无广告、第三方自建后端或统计 SDK；保留证书校验，禁止文件访问和混合内容，不使用 `addJavascriptInterface`。

## 构建

JDK 17、Android SDK 35、Gradle 8.9：`gradle :app:assembleDebug`。

本地无 Gradle 构建：设置 `ANDROID_LOCAL_TOOLS`（包含 `ecj.jar`、`android-35/android.jar`、`android-15` build-tools），执行 `bash build-local.sh`。专用签名密钥在项目外 `private` 目录；请私下保留，不要公开上传。

## 发布后续版本

保持同一应用签名，递增 Android versionCode；发布对应 GitHub Release 和 APK，再更新根目录 `update.json` 的版本、下载地址、说明、大小与 SHA-256。当前版本 1.4.0（versionCode 5）。

## 验证与范围

`npm install` 后执行 `npm test`：

- 8 项模拟流程覆盖通过、错误答案、403、断网、已完成同步、超时提交编号保留、勋章分页、草稿及防重复提交。
- 勋章折叠 / 展开、大图详情、日期标签及关闭交互。
- DOM 检查题目渲染和 HTML 清理、语言选择、高亮与编辑；确认不再存在原文入口及资料卡账号按钮。
- 模拟 A/B 账号切换、草稿隔离、退出后资料刷新及只读账号状态通道。
- 官方表单协议检查就绪、单次显式提交、错误、状态消息不含密码、额外验证/OTP 保留及已登录结果。未在真实账号上验证密码登录。

更新策略 JVM 测试覆盖当前 / 新版 / 旧版 / 无效版本，以及不可信下载地址拒绝。

Chromium 133 的 390×844 视口检查主界面；APK 编译、v2/v3 签名、资源一致性及升级签名校验通过。尚未进行 Android 真机登录、真实判题或积分到账测试。
